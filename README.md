# Attimo releases

Downloads for **Attimo**, a free native macOS app that puts what's playing, your day and your tools in the
notch. Attimo was formerly called Oriel and, before that, LocalNook.

This repository holds only the release downloads and their notes. Attimo's source code is not published here.

**No release has been published here yet.** When the first one is, it will be listed under Releases.

## Download

Each release will have two files:

- `Attimo-<version>.dmg`: open it and drag Attimo to Applications.
- `Attimo-<version>.zip`: the same app, used by Attimo's built-in updater.

## Coming from Oriel

Oriel does not update itself to Attimo: install Attimo by hand, once. The first time it opens, Attimo brings
over Oriel's settings, files and saved keys. macOS treats Attimo as a new app, so a few things are done once
more (permissions, the fan helper, the Claude Code and Codex links, the iPhone pairing); Settings ▸ About ▸
Coming from Oriel lists them. Keep Oriel until Attimo works for you.

Earlier Oriel releases stay at https://github.com/Kkray19/Oriel-releases.

## Free, under the Attimo End User License Agreement

Attimo is free: there is no price, subscription or paid tier. You use it under the Attimo End User License
Agreement, which you accept, together with the Privacy Policy, the first time you open Attimo. Both documents
are also in the disk image, beside the app.

## Updates

If the update check is on (Settings ▸ About), Attimo asks this repository about once a day whether a newer release
exists. It tells you when one does, and downloads one only when you press Install and Relaunch. It installs
only a copy signed by the same developer as the one you are running.

## Privacy

The Privacy Policy, which is also in the disk image, says what Attimo collects, what each online feature
sends, and when.

## Requirements

macOS 15 or later, on a Mac with Apple silicon.

## Questions and privacy requests

Write to the address given in the License Agreement and the Privacy Policy. Please don't send passwords, keys
or other sign-ins.

## Source code

This repository does not contain Attimo's source code. Parts of Attimo are open-source software under their own
licences. The fan helper is under the GNU General Public License v3.0 or later, and its complete source is
published with each release. `Attimo-Source-Offer.txt`, in the app and in the disk image, says where to get the
source of each open-source part and what each licence requires.
